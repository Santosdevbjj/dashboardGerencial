# 📊 Dashboard Gerencial para Tomada de Decisões com Power BI

Este projeto tem como objetivo **criar e aprimorar um Dashboard Gerencial** para apoiar **a tomada de decisões estratégicas** em ambientes corporativos.  
O desafio foi desenvolvido com base no material do curso **“Atualizando Relatório Financeiro com Foco na Experiência do Usuário”**, aplicando princípios de **UX em relatórios de BI**.

---

## 🎯 Objetivos do Projeto

- Modificar o relatório inicial focando na **experiência do usuário**;
- Aplicar conceitos de **posicionamento, contraste, proporção áurea e segmentação**;
- Criar **botões de navegação** e menus interativos;
- Construir uma **matriz de descrição de vendas**;
- Demonstrar o processo completo de criação mesmo **sem o Power BI instalado**.

## ⚙️ Tecnologias Utilizadas

- **Microsoft Power BI Desktop** (para construção do dashboard)
- **Power Query (M Language)** para tratamento e transformação de dados
- **DAX (Data Analysis Expressions)** para criação de medidas e KPIs
- **SQL** para integração com fontes de dados
- **Excel / CSV** como base de dados auxiliar
- **GitHub** para versionamento e colaboração

## 🚀 Como Executar o Projeto (Com e Sem Power BI)

### ✅ Caso tenha o Power BI Desktop
**1. Baixe o repositório ou clone:**
   ```bash
   git clone https://github.com/Santosdevbjj/dashboardGerencial


---
```

**2. Abra o arquivo**
/models/dashboard_gerencial_final.pbix.


**3. Conecte-se às fontes de dados em /data.**


**4. Visualize o relatório completo.**



⚙️ **Caso não tenha o Power BI instalado***

Você pode explorar o projeto de três formas alternativas:

**1. Visualização Online no Power BI Service**

Acesse Power BI Service

Faça upload do arquivo dashboard_gerencial_final.pbix

Utilize os botões interativos diretamente no navegador



**2. Simulação via Power BI Report Builder**

Instale o Power BI Report Builder (gratuito)

Importe os dados .csv da pasta /data

Crie relatórios estáticos baseados nos modelos descritos em /docs/modelagem_dados.md



**3. Leitura Manual com Documentação**

O arquivo /docs/instrucoes_sem_powerbi.md explica passo a passo como reproduzir a estrutura do dashboard manualmente:

Modelagem dos dados no Excel

Criação dos gráficos de área, matriz e botões

Aplicação de estilo visual e segmentação
